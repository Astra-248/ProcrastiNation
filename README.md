### Project Description

ProcrastiNation is a playful React web app for people who are trying to finish tasks but would rather generate increasingly elaborate excuses. Users add a task, create excuses, improve them, and watch their productivity guilt rise in a deliberately unhelpful interface.

### The Problem (that doesn't exist)

People are completing tasks too efficiently and are losing valuable time that could have been spent overthinking, refreshing tabs, and preparing emotionally to begin.

### The Solution (that nobody asked for)

ProcrastiNation turns procrastination into a guided experience. It gives every task a dramatic excuse, escalates the guilt meter, and adds enough playful resistance to make postponing work feel like a fully designed product feature.
